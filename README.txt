MICROPRECITECH ENGINEERING — PREMIUM MULTI-PAGE STATIC WEBSITE

PROJECT STRUCTURE
-----------------
index.html          Home page
about.html          Company / About page
services.html       Services and capabilities
machinery.html      Machinery and specifications
products.html       Products / components
industries.html     Industries served
gallery.html        Photos and CNC videos
contact.html        Contact and enquiry page
styles.css          All shared website styling
script.js           Shared JavaScript interactions
Media/              Supplied component photos and CNC videos

HOW TO EDIT
-----------
1. Open the project folder in VS Code.
2. Edit page content directly inside the relevant HTML file.
3. Edit colours, spacing, fonts and responsive layout in styles.css.
4. Edit navigation/highlighting/mobile behaviour in script.js.
5. Keep the Media folder paths unchanged unless you also update the HTML references.

QUICK CONTENT CHANGES
---------------------
- Home hero text: index.html -> section class="hero"
